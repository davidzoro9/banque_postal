# Banque Postale - SIRH & Gestion de la Paie

Application Full-Stack de gestion des Ressources Humaines et de la Paie pour la Banque Postale.

## Structure du projet
- sanou/ : Backend Spring Boot (Java 21, PostgreSQL, JPA/Hibernate, Spring Security)
- sigrh_frontend/ : Frontend Angular 19+ (Angular Material, Signals, RxJS, Chart.js)
- docker-compose.yml : Configuration Docker pour PostgreSQL et les services
- mes_donnees_locales.sql : Scripts d'initialisation et données de référence
